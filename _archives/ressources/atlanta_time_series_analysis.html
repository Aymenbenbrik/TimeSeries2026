Time Series Analysis of Atlanta Temperatures

Aymen Ben Brik

2026-03-05

Introduction

This document analyses monthly temperature data from Atlanta.
The objective is to:

  • Import and format the data
  • Create a time series object
  • Estimate the trend
  • Estimate the seasonality
  • Remove trend and seasonality
  • Study the autocorrelation of residuals

1. Data Import and Preparation

# Read the text file containing Atlanta average temperatures
data = read.table("AvTempAtlanta.txt", header = T)

# Display column names
names(data)
##  [1] "Year"   "Jan"    "Feb"    "Mar"    "Apr"    "May"    "Jun"    "Jul"   
##  [9] "Aug"    "Sep"    "Oct"    "Nov"    "Dec"    "Annual"
# Visualize the dataset
View(data)

# Remove column 1 and 14 (often year and annual average)
data = data[,-c(1,14)]

# Check the data after removing columns
View(data)

# Show help for as.vector
help(as.vector)
## démarrage du serveur d'aide httpd ... fini
# Transpose the matrix and convert it into a vector
# This ensures observations are ordered month by month
data = as.vector(t(data))

# View the resulting vector
View(data)

2. Create the Time Series

# Create a monthly time series starting in 1879
temp = ts(data, start = 1879, frequency = 12)

# Verify object class
class(temp)
## [1] "ts"
# Plot the time series
ts.plot(temp, ylab = "temperature")
